# Журнал змін

## v1.0.0

Реєстр SQLite з унікальним ключем подання, читання за номером, повторна відповідь HTTP 200 і лічильники HTTP-результатів.

## v2.0.0

Після коміту імітується видача квитанції з номером подання. Прапорець FAIL_CONFIRMATION імітує тайм-аут квитанції та повертає HTTP 503 зі збереженим номером. Схема SQLite сумісна з v1.
